## Could not verify

- **Anything authenticated or live.** Per the brief I made no authenticated call to the reachable homeserver. The sync loop against a real server, a real `/search`, a real `/context`, real member lists, real bridge notices, and the CLI against real joined rooms are all unexercised; the smoke script's authenticated section is skipped without `MATRIX_*`.
- **E2EE for real.** No crypto helper was initialised, so decryption of an actual encrypted room, the `undecryptable` placeholder against a real undecryptable event, and `prepareEncryption`'s member-cache path against a live server are unproven — and, per R7, untested locally too.
- **Streamable HTTP session lifetime.** I did not run a live MCP client against `MCP_TRANSPORT=http`; the `WriteTimeout: 0` rationale in `main.go:142-152` is established from net/http deadline semantics and code reading, not observation.
- **A webhook receiver.** No live endpoint, so the 5s timeout and single retry are verified by `httptest` (`TestWebhookTimesOut`, `TestWebhookExactlyOneRetry`) and by `TestNewDispatcherDefaults` pinning the shipped constants.
- **A working tree credential.** This checkout contains an untracked, gitignored `.env` holding a Matrix access token (not reproduced here). It is not tracked and appears nowhere in `git log --all`, so there is no repository exposure; I did not use it and did not verify whether it is valid.
